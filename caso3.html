Caso de uso 3

Segmentación de clientes

Este caso de uso usa Aprendizaje No Supervisado, un tipo de Machine Learning que sirve para encontrar grupos ocultos dentro de los datos. Aquí queremos agrupar a los clientes de una empresa según sus características y comportamiento de compra, sin decirle al modelo de antemano cuáles son los grupos correctos.

Problema

¿Qué necesitamos resolver?

Una empresa tiene muchos clientes distintos y les envía a todos la misma publicidad. Esto es poco efectivo porque no todos los clientes compran igual ni buscan lo mismo. Se necesita agruparlos para entenderlos mejor.

Datos

¿Qué datos usaríamos?

Datos de cada cliente como: edad, frecuencia de compra, monto total gastado, categorías de productos que prefiere y forma de pago. Estos datos no tienen una etiqueta o respuesta correcta previa.

Modelo

¿Qué haría el modelo?

El modelo analiza las características de todos los clientes y busca similitudes entre ellos. Con base en eso, arma grupos (clusters) de clientes parecidos, por ejemplo: "compradores frecuentes de bajo gasto" o "compradores ocasionales de alto gasto".

Tipo de ML

Aprendizaje No Supervisado - Clustering

Es no supervisado porque los datos no tienen una respuesta correcta previa: nadie le dice al modelo a qué grupo pertenece cada cliente. El modelo los descubre solo. Ejemplo de algoritmo simple: K-Means.

Beneficio

¿Para qué sirve esto?

Permite crear promociones y mensajes de marketing pensados para cada grupo de clientes, mejora la relación con ellos y aumenta las probabilidades de venta al ofrecer justo lo que cada grupo busca.
