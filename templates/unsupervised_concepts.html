Activity 3 | Core Concepts

Unsupervised Machine Learning

Learn how clustering finds structure in unlabeled data, and how the K-Means model is applied to social media and digital behavior.

Definition

What Is Unsupervised Learning?

Unsupervised Machine Learning analyzes features without a target label. The algorithm looks for structure in the observations, such as groups, shared patterns, or unusual records. The resulting groups require interpretation using domain context.

Comparison

Supervised vs. Unsupervised

Supervised learning uses labeled examples to learn a mapping from inputs to known outcomes, such as a class or numeric value. Unsupervised learning has no target column; it organizes observations using similarities among their features.

Grouping

Clustering

Clustering assigns observations to groups so that members of a cluster are relatively similar under a chosen distance measure. The groups are discovered from the data rather than supplied as ground-truth labels.

Algorithm

K-Means

K-Means partitions observations into a chosen number, K, of clusters. It repeatedly assigns each point to its nearest centroid and recomputes each centroid as the mean of the assigned points. The objective is to reduce within-cluster squared distances.

Cluster Center

Centroids

A centroid is the mean feature vector of observations assigned to a cluster. It summarizes the center of that group. In this project, centroid values are converted back to the original units to make the profiles easier to interpret.

Optimization

Iterations

One iteration consists of assigning points to their nearest centroids and recalculating the means. K-Means repeats these steps until assignments stop changing or an iteration limit is reached. The final result can depend on initial centroid placement.

Preprocessing

Standardization

Features use different units and ranges. StandardScaler centers each feature around its mean and scales it by its standard deviation. This prevents large numeric scales from dominating Euclidean distance. The same fitted scaler is applied to profiles submitted for prediction.

Evaluation

Silhouette Score

The silhouette score compares how close a point is to its own cluster with how close it is to the nearest alternative cluster. Scores range from -1 to 1; higher values indicate clearer separation. It is not classification accuracy and does not prove that clusters are objectively correct.

Project Application

Social Media Usage and Digital Behavior Clustering

This activity uses 1,200 records and five numeric features: age, daily social media hours, daily screen time hours, posts per week, and messages per day. The features are standardized and clustered with K-Means using K = 3. There is no target variable or 80/20 train-test split. The resulting groups are interpreted by comparing their centroids.
