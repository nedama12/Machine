Use case 4

Vehicle Demand Forecasting

This use case relies on Supervised Learning, the type of Machine Learning that learns from historical data where the correct answer is already known. The goal is to predict how many vehicles will be needed over the coming days, using historical demand records.

Problem

What do we need to solve?

A transport or vehicle rental company does not know how many vehicles it will need each day. With too few, it loses customers; with too many sitting idle, it spends more than necessary on maintenance.

Data

What data would we use?

The daily history of vehicles in use, the date, the day of the week, the season of the year (holidays, public holidays), and special events or weather that may affect the number of trips.

Model

What would the model do?

From the historical records, the model learns how demand varies with the date and other conditions. Then, given a future date, it computes a number: the quantity of vehicles that will be needed that day.

ML Type

Supervised Learning — Regression

It is supervised because we use historical data where the real number of vehicles used each day is already known. It is regression because the result we want is a number. A simple algorithm example: Linear Regression.

Benefit

What is this useful for?

It helps keep exactly the right number of vehicles available, cuts unnecessary maintenance costs, and improves customer satisfaction by never leaving them without service.
