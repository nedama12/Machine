Use case 1

House Price Prediction

This use case relies on Supervised Learning, the type of Machine Learning that learns from historical data where the correct answer is already known. The goal is to predict a house's price from its characteristics, using examples of homes that were already sold before.

Problem

What do we need to solve?

A real-estate agency wants to know at what price to list a home, but calculating it by hand for every case is slow and inconsistent. A method is needed to estimate the price faster and more objectively.

Data

What data would we use?

Data from homes already sold: area in square meters, number of bedrooms and bathrooms, location, age, and the final price each one sold for.

Model

What would the model do?

From the homes already sold, the model learns how those characteristics relate to the final price. Then, given the data of a new home, it computes an estimated price.

ML Type

Supervised Learning — Regression

It is supervised because we use data where the real price of each home is already known. It is regression because the result we want is a number. A simple algorithm example: Linear Regression.

Benefit

What is this useful for?

It helps set fairer, more consistent prices, reduces the time spent analyzing each property, and gives more confidence to both buyers and sellers.
