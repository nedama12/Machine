Reinforcement Learning

Reinforcement Learning (RL) is a type of Machine Learning in which an agent learns to make decisions by interacting directly with an environment. Instead of learning from a labeled dataset, the agent learns from experience: it tries actions, observes what happens, and gradually improves its behavior based on the rewards and penalties it receives.

In this project, the agent is a virtual robot that must cross a 10×10 grid from a starting cell to a target cell, avoiding walls and minimizing time spent in danger zones. Every concept explained below is illustrated using this exact exercise.
01

Agent

The decision-maker. In our exercise, the agent is the virtual robot that moves across the grid one cell at a time, choosing an action at every step.

02

Environment

Everything the agent interacts with. Here, the environment is the 10×10 grid together with its movement rules: walls block movement, danger zones penalize the agent, and the target ends the episode.

03

State

A snapshot of the situation at a given moment. In this exercise, the state is simply the agent's current position, expressed as a (row, column) pair, for example (0, 0) at the start.

Core Building Blocks

Use the accordion below to review each remaining concept in detail, always connected to the grid exercise implemented in the Application page.

An action is a choice the agent can make at a given state. In this exercise there are exactly four possible actions: Up, Down, Left and Right. Each action moves the robot one cell in that direction, if the move is valid.

A reward is the numeric feedback the environment gives the agent after an action. A positive reward encourages a behavior, while a negative reward (penalty) discourages it. In our grid, reaching the target gives a large positive reward, while hitting a wall, attempting an invalid move, or entering a danger zone produce different negative rewards, as shown in the Reward System table on the Application page.

The policy is the strategy the agent follows to choose an action for each state. At the beginning, the policy is essentially random. After training, the policy tends to pick the action with the highest estimated value at each cell of the grid, which is what produces the final learned path shown after training.

A step is a single state-action-reward-next state transition, for example moving from (0, 0) to (0, 1). An episode is a complete attempt that starts at the initial cell (0, 0) and ends either when the agent reaches the target or when it uses up the maximum number of allowed steps.

Experience is the record of what the agent observed at every step: the state it was in, the action it took, the reward it received and the next state it landed on. Each of these transitions is what the agent uses to update its Q-value estimates.

Exploration means trying random actions to discover new parts of the grid, even ones that may not seem optimal yet. Exploitation means choosing the action that currently looks best according to the agent's own estimates. A good agent needs both: enough exploration to discover the target and avoid danger zones, and enough exploitation to actually use what it has learned.

The Epsilon-Greedy strategy balances exploration and exploitation using a probability ε (epsilon). With probability ε, the agent picks a random action (exploration); otherwise, it picks the action with the highest known Q-value (exploitation). ε starts high so the agent explores the grid freely, and decays over the training episodes so the agent increasingly relies on what it has learned.

The immediate reward is the single reward received right after one action. The return is the accumulated sum of rewards the agent expects to collect from a state until the episode ends. Because future rewards are less certain than immediate ones, they are multiplied by a discount factor (γ) between 0 and 1. In this exercise γ = 0.95, meaning the agent strongly values future rewards (such as finally reaching the target) while still slightly favoring faster paths.

V(s) estimates how good it is to be in a given cell, assuming the agent then follows its current policy. Q(s, a) is more specific: it estimates how good it is to take a particular action from a particular cell. The Application page displays, for every walkable cell, the learned Q-values for the four possible actions.

Q-Learning is the algorithm used to estimate Q(s, a) from experience, without needing a manually programmed path. After every step, the agent updates its estimate of Q(s, a) using the reward it just received plus the discounted value of the best action available at the next state. In this implementation, Q(s, a) is estimated with an SGDRegressor: predict() reads the current Q-value estimates and partial_fit() applies the Q-learning correction after each observed transition, exactly as in the reference classroom exercise.
