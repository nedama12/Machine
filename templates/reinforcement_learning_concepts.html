Reinforcement Learning Concepts

Reinforcement Learning (RL) is a way of learning by interaction: an agent tries actions in an environment, receives rewards or penalties, and gradually discovers which behavior maximizes the reward it collects over time. In this project the agent learns to cross a {{ rows }}×{{ cols }} grid with walls and danger zones.

No labeled data is used. Unlike supervised learning, nobody tells the agent the correct route. It only receives a numeric reward after each move and must find the best route by itself.

Core elements in this exercise

Agent

The virtual robot that starts in cell A (0,0) and must reach the target T. It is the one that learns.

Environment

The {{ rows }}×{{ cols }} grid and its movement rules: free cells o, walls #, danger zones D and the target T.

State

The agent's current position as (row, column), for example (3,4). There are {{ rows * cols }} possible positions.

Action

One of four moves: Up, Down, Left, Right.

Reward

A positive signal. Here only reaching the target gives a positive value ({{ rewards[4][2] }}).

Penalty

A negative reward: every normal step, hitting a wall, leaving the grid and entering a danger zone all cost points.

The Q-Learning update

Target for Q(s,a)

r + γ max Q(s2,a2)

s = current cell

a = action taken

r = immediate reward

s2 = next cell

γ = {{ gamma }}

max Q(s2,a2) = best value available from s2

Exploration vs. exploitation: if the agent only exploited from the beginning it could settle on a mediocre route (for example crossing a Danger Zone); if it only explored it would never use what it learned.
