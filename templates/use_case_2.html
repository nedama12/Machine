Use case 2

Email Spam Detection

This use case relies on Supervised Learning, the type of Machine Learning that learns from historical data where the correct answer is already known. The goal is to have the model review an email and say whether it is spam or not, using previous emails that were already labeled.

Problem

What do we need to solve?

Email users receive unwanted messages that fill up the inbox and can be dangerous (phishing, misleading ads). Reviewing every email by hand is slow and impractical.

Data

What data would we use?

A set of previous emails already labeled as "spam" or "not spam", along with their content: subject, message body, sender, and whether they contain links or attachments.

Model

What would the model do?

From the emails already labeled, the model learns which words and patterns tend to appear in spam messages. With that, when a new email arrives, it decides which category it belongs to.

ML Type

Supervised Learning — Classification

It is supervised because we use emails where it is already known whether they are spam or not. It is classification because the result we want is a category. A simple algorithm example: Naive Bayes.

Benefit

What is this useful for?

It keeps the inbox cleaner, reduces the risk of falling for fraud or dangerous links, and saves users time by not having to review unnecessary emails.
