Linear Regression Concepts

Linear Regression is a supervised learning method that learns a numerical relationship from examples and predicts a continuous value.

What is Linear Regression?

It fits a regression line that represents the relationship between an input and an output in the training data.

Simple Linear Regression

It uses one independent variable. This project uses only Sunlight Hours; the other columns are complementary information.

Training Data

The 1,096 daily records from Bogota provide pairs of sunlight hours and recorded solar energy production.

Regression Equation

y = mx + b

x = Sunlight Hours

y = Solar Energy (kWh/day)

m = Slope ({{ "%.4f"|format(coefficient) }})

b = Intercept ({{ "%.4f"|format(intercept) }})

How does the line work?

The regression line summarizes the relationship between X and Y. Its slope estimates how solar energy changes for each additional sunlight hour, while the intercept is the prediction when X is zero.

For example, entering 7 hours makes the trained model use x = 7 to produce a prediction.

Why supervised regression?

This is Supervised Learning because every record includes an input and a known outcome. It is Regression, not Classification, because the result is a continuous value in kWh/day, not a category.
