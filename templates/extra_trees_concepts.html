Supervised Learning

Extra Trees Classifier

Extra Trees Classifier is a supervised machine learning algorithm based on an ensemble of randomized decision trees. It is used to classify observations into different categories.

01

Definition

Extra Trees creates multiple decision trees and combines their predictions to obtain a final classification.

02

How It Works

The algorithm introduces randomization when creating decision trees and combines their results.

03

Classification

It can be used for classification problems with two or more classes.

Characteristics

TREES

Multiple Trees

The model uses an ensemble of decision trees to make its predictions.

RANDOM

Randomization

Random selection is used when creating the decision trees.

DATA

Multiple Variables

The model can work with several independent variables at the same time.

Advantages and Limitations

ADVANTAGES

Strengths

It can handle several variables, capture complex relationships and reduce dependence on a single decision tree.

LIMITATIONS

Considerations

The model can require more computational resources because it uses many decision trees.

Real-World Example

Extra Trees can be used in credit risk analysis to classify customers according to financial characteristics such as income, debt, credit score and age.

OUR PROJECT

Credit Risk Classification

In this project, the model uses four independent variables to classify an application as low risk or high risk.

0 = Low Risk
