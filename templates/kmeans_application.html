Dataset and Feature Selection

This dataset was selected to explore patterns in social media use and broader digital behavior across 1,200 user records. Age provides demographic context; daily social media hours and daily screen time describe time spent using digital platforms; posts per week and messages per day describe interaction frequency. Together, the five numerical variables represent distinct but related aspects of users' digital activity.

Preprocessing and Clustering

The five numerical variables were selected as model inputs. StandardScaler was fitted and applied to those variables, and K-Means was fitted to the standardized data with three clusters. No train/test split was used because this is an unsupervised clustering task without a target label or supervised prediction evaluation.
