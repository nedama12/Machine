Supervised Learning

Logistic Regression

Logistic Regression is a supervised learning algorithm used to classify data into categories based on one or more independent variables.

01

Classification

Classification assigns data to predefined classes according to the characteristics of each observation.

02

Binary Classification

Binary classification uses two possible classes. In this project, the classes are rejected and approved.

03

Probability

The model estimates the probability that an observation belongs to a specific class.

Variables and Labels

The independent variable is the information used by the model to make the prediction. The dependent variable is the result that the model tries to predict.

INPUT

Monthly Income

Independent variable: the applicant's monthly income in Colombian pesos.

TARGET

Credit Approval

Dependent variable and target label used for classification.

LABELS

0 and 1

0 = Credit Rejected
1 = Credit Approved

Classification Threshold

Logistic Regression produces a probability between 0 and 1. A threshold is used to transform that probability into a class prediction.

THRESHOLD

0.5

When the estimated probability is at least 0.5, the observation is classified as class 1. Otherwise, it is classified as class 0.

Logistic Regression vs Linear Regression

Linear Regression Logistic Regression
Predicts continuous values. Predicts categories.
Used for regression problems. Used for classification problems.
Output can take many numerical values. Output represents class probabilities and labels.
Example: solar energy production. Example: credit approval.
