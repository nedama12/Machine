Use case 3

Customer Segmentation

This use case relies on Unsupervised Learning, the type of Machine Learning used to uncover hidden groups inside a dataset. The goal is to group a company's customers by their characteristics and buying behavior, without telling the model beforehand which groups are the correct ones.

Problem

What do we need to solve?

A company has many different customers and sends the same advertising to all of them. That is not effective, because not every customer buys the same way or looks for the same things. They need to be grouped to be understood better.

Data

What data would we use?

Customer data such as age, purchase frequency, total amount spent, preferred product categories, and payment method. This data has no label or known correct answer beforehand.

Model

What would the model do?

The model analyzes the characteristics of every customer and looks for similarities among them. Based on that, it builds groups (clusters) of similar customers, for example: "frequent low-spend buyers" or "occasional high-spend buyers".

ML Type

Unsupervised Learning — Clustering

It is unsupervised because the data has no previous correct answer: nobody tells the model which group each customer belongs to. The model discovers them on its own. A simple algorithm example: K-Means.

Benefit

What is this useful for?

It makes it possible to design promotions and marketing messages tailored to each customer group, improves the relationship with them, and increases the chance of a sale by offering exactly what each group is looking for.
