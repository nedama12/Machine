Reward System

Situation Reward
Moving to a valid normal (open) position{{ reward_step }}
Attempting an invalid movement (outside the grid){{ reward_invalid_move }}
Hitting a wall{{ reward_wall }}
Entering a danger zone{{ reward_danger_zone }}
Reaching the goal+{{ reward_goal }}

Small negative rewards push the agent toward shorter routes. Hitting a wall is penalized more than an ordinary step so the agent learns to avoid obstacles, and a danger zone is penalized even more heavily so the agent prefers to go around it whenever a safer route exists — but it is still allowed to cross one if that is the only way forward. The large positive reward for reaching the target is what ultimately drives the agent toward the goal.

ε starts at {{ epsilon_start }} so the agent explores freely, and is multiplied by {{ epsilon_decay }} after every episode until it reaches the floor of {{ epsilon_min }}, guaranteeing a small amount of exploration even late in training. γ = {{ gamma }} makes the agent value future rewards strongly, which is necessary on a grid this large.
