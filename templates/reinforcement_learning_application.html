Grid World Q-Learning

An agent starts in cell A and must reach the target T on a {{ rows }}×{{ cols }} grid. It learns by trial and error, using an Epsilon-Greedy strategy and a Q-value model trained incrementally with SGDRegressor. The route shown after training is not programmed: it comes from the learned Q-values.

Reward system

{% for situation, cell, value in rewards %} {% endfor %}
SituationCell typeReward
{{ situation }}{{ cell }}{{ value }}

A small cost per step pushes the agent to find short routes, walls cost more than a plain step so bumping is never useful, a Danger Zone costs enough that a detour of a few cells is better than crossing it, and the large goal reward gives every route a reason to end at T. The agent can enter D, but pays for it. Episodes end at T or after {{ config.max_steps_training }} steps.

  • ε = {{ config.epsilon_start }} → {{ config.epsilon_min }}, decay {{ config.epsilon_decay }}: the agent explores almost purely at the start; after about 500 episodes it is near the floor, so the remaining episodes refine the route while 5% of moves still explore.
  • γ = {{ config.gamma }}: far-sighted enough for the target reward to reach the start cell (18 moves away), without making distant rewards count as much as immediate ones.
  • {{ config.episodes }} episodes: enough for the Q-values to propagate across the whole grid while keeping the training button fast.
  • Learning rate {{ config.learning_rate }} and batches of {{ config.batch_size }}: small, stable corrections taken from replayed experiences instead of a single step.
  • Seed {{ config.seed }}: makes the run reproducible.

Training runs on the server when the button is pressed and takes a few seconds.
